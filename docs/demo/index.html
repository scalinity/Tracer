Tracer

Between a specimen's collection scan and its receipt scan in the laboratory, there is no record. Tracer re-scores every unreceived specimen on a clock tick, estimates the chance it misses its stability window and where it probably is, and alerts while it can still be recovered.

Synthetic data, no clinical review. Every specimen here was written by a language model from briefs drawn by seeded code, and no clinical scientist has reviewed the data or the model. Every parameter is an assumption, and the same assumptions shaped both the data and the model. The alert budget is generous: a large share of all specimens get an alert. Warning means the minutes from an alert to the window closing.

        Set the threshold

        An alert threshold is a trade. Set it low and Tracer warns early, and alerts on many specimens that would have arrived anyway; set it high and it alerts less, and later. The plan's rule makes the same trade with a time limit. Move the threshold to see both methods on the held-out runs. The board and the timeline above follow it.

        Limits

        • The data is synthetic. A language model wrote every scan event from briefs drawn by seeded code. No laboratory's data is in it.
        • There was no clinical review of the data or the model.
        • Every parameter is an assumption: the transit times, the stall and loss rates, the tier weights and the alert roles. A stability window with a published source shows its citation; the others say assumed.
        • The data and the model share assumptions. The model was fitted to data written under the same assumed timings, so a good result here shows the method behaves as designed, not that it works in a real laboratory.
        • The alert budget is generous. A large share of all specimens get an alert, and most of those specimens arrive in time.
        • Warning is the minutes from an alert to the stability window closing. An alert at or after the close does not count as a catch.
        • Where a specimen probably is comes from the workflow map, not from any observation, and the estimate stops at the demo's horizon.
